# PetPurple 🐾

Projeto Site Pet — Programação Front-End (3T).

## Páginas
- `index.html` — Home, imagem aleatória da [Dog API](https://dog.ceo/) e seção **Sobre** com vídeo incorporado
- `servicos.html` — Cards de serviços (Banho, Ração, Vacina) com flexbox
- `compra.html` — Agendamento pelo WhatsApp
- `contato.html` — Formulário de contato que envia a mensagem pelo WhatsApp

## Tecnologias
HTML, CSS (flexbox, media queries) e JavaScript (fetch/async-await).
